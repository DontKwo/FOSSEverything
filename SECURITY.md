# Security Policy

## Supported Versions & Official Releases

| Version / Branch | Supported | Notes |
| :--- | :--- | :--- |
| `main` (Latest `vX.Y.Z` Release) | Yes | Actively maintained official release stream |
| Forks, Mirrors, and Older Tags | No | Unverified and unsupported |

Official executables and packages are distributed exclusively from the primary `DontKwo/FOSSEverything` repository on GitHub (`main` branch and official [Releases](https://github.com/DontKwo/FOSSEverything/releases/latest)).

- **Fork Safety Warning**: Do **not** download or run executables from forked repositories or third-party mirrors unless you have inspected the source code yourself and confirmed they contain no malware. Only official `main` releases are maintained by the author, and I make no promises.
- **OS Security Prompts**: Because `FOSSEverything` is published independently without paid commercial code-signing certificates, Windows SmartScreen and macOS Gatekeeper will likely warn that downloaded binaries are unrecognized or unsafe. Review [Desktop Installation Guide](docs/INSTALLATION.md) and bypass prompts strictly at your own discretion.

## Reporting a Vulnerability

If you discover a security vulnerability in `DontKwo/FOSSEverything`:

1. **Do not** publish exploit details in a public GitHub Issue.
2. Open a [Private Vulnerability Report](https://github.com/DontKwo/FOSSEverything/security/advisories/new) on GitHub (or contact `@DontKwo` directly via GitHub).
3. Include reproduction steps, platform details, and any suggested fix.
